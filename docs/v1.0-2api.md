## Issue #2 — Player 玩家类（lfk → 供 #5 #6 #7 调用）

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| userId | int | - | 唯一标识 |
| playerName | String | - | 昵称 |
| currentRoom | Room | 构造传入 | 当前房间 |
| previousRooms | Stack\<Room\> | 空栈 | 历史路径 |
| bag | List\<AbstractItem\> | 空列表 | 背包 |
| maxCapacity | int | 50 | 负重上限 |
| attack | int | 10 | 攻击力 |
| defense | int | 5 | 防御力 |
| currentHealth | int | 100 | 当前血量 |
| maxHealth | int | 100 | 最大血量 |
| isOnline | boolean | false | 在线状态 |

### 对外接口（#4 #5 #6 #7 会调用）

```java

// 战斗属性 — v1.0 预留，v2.0 #11 启用
```

## Issue #5 — GoCommand / BackCommand / HelpCommand（lfk → 供 Game 调用）

### 共通的 Command 签名

**包路径：** `cn.edu.whut.sept.zuul.game.Command`

```java
// ★ 关键改动：增加 Player 参数
abstract boolean execute(Game game, Player player);

String getSecondWord()
boolean hasSecondWord()
void setSecondWord(String word)
```

### GoCommand

```
包：cn.edu.whut.sept.zuul.game.command.GoCommand
继承：Command

execute(game, player):
  1. 无 secondWord → 提示 "Go where?"
  2. currentRoom.getExit(direction) 获取目标
  3. 如果目标 isPortal() → 改为 game.getRandomRoom()，提示传送
  4. player.moveTo(targetRoom)
  5. 输出 targetRoom.getLongDescription()
  6. 全程通过 game.getMessageBridge().send() 输出
```

### BackCommand

```
包：cn.edu.whut.sept.zuul.game.command.BackCommand
继承：Command

execute(game, player):
  1. previousRoom = player.goBack()
  2. 如果 null → 提示 "You are at the starting point!"
  3. 否则输出 previousRoom.getLongDescription()
  4. 可连续回退（每次回到上一个房间）
```

### HelpCommand

```
包：cn.edu.whut.sept.zuul.game.command.HelpCommand
继承：Command

execute(game, player):
  输出命令列表：
    go <direction>  - move
    back            - return to previous room
    look            - view room
    take <item>     - pick up item
    drop <item>     - drop item
    use <item>      - use item
    items           - show items
    help            - show help
    quit            - quit game
```

## Issue #6 — TakeCommand / DropCommand / UseCommand（gmy → 供 Game 调用）

### TakeCommand

```
包：cn.edu.whut.sept.zuul.game.command.TakeCommand
继承：Command

execute(game, player):
  1. 无 secondWord → "Take what?"
  2. room.getItem(name) → null 则 "No such item here."
  3. player.canCarry(item) → false 则 "Too heavy! Max: XX"
  4. room.removeItem(name)   // 从房间拿走
  5. player.takeItem(item)   // 加入背包，触发 item.takenBy(player)
  6. 提示 "You took the XX."
```

### DropCommand

```
包：cn.edu.whut.sept.zuul.game.command.DropCommand
继承：Command

execute(game, player):
  1. 无 secondWord → "Drop what?"
  2. 遍历 player.getBag() 找到物品 → null 则 "You don't have this."
  3. player.dropItem(item)   // 从背包移除，触发 item.droppedBy(player)
  4. room.addItem(item)      // 放回房间
  5. 提示 "You dropped the XX."
```

### UseCommand

```
包：cn.edu.whut.sept.zuul.game.command.UseCommand
继承：Command

execute(game, player):
  1. 无 secondWord → "Use what?"
  2. 遍历 player.getBag() 找到物品 → null 则 "You don't have this."
  3. 判断是否为装备（Equipment）→ 若是则提示 "Cannot use equipment."
  4. player.useItem(item)    // 触发 item.usedBy(player)，道具自动从 bag 移除
  5. 提示 "You used the XX."
```

## Issue #7 — 传送房间（lfk → 在 #3 和 #5 中实现）

无独立类，逻辑分散在 Room 和 GoCommand 中：

### Room 侧

```java
boolean isPortal()                        // 返回 portal 字段
void setPortal(boolean)
Room getRandomExit(List<Room> allRooms)   // 传入 Game.getAllRooms()
                                          // 过滤：排除自身 + 排除 isPortal() 的其他房间
                                          // 从剩余中随机选一个返回
```

### GoCommand 侧

进入传送房间时代替原来的出口方向：
```
如果 nextRoom.isPortal():
    提示 "A mysterious force transports you..."
    nextRoom = game.getRandomRoom()
```

### Game 侧

```java
Room getRandomRoom()           // 从 allRooms 中随机选一个非 portal 房间

```

## Issue #8 — 消息系统（gmy → 供 #5 #6 #7 所有 Command 调用）

### 消息类型

| 类 | type | 用途 |
|----|------|------|
| GlobalMessage | "global" | 欢迎语、退出等全局消息 |
| RoomWideMessage | "room" | 玩家进入/离开房间通知（v2.0） |
| SinglePlayerMessage | "single" | 命令执行结果、错误提示 |

### 桥接层

```java
// 抽象层
AbsMessageBridge:
    abstract void send(IMessage message)
    abstract void send(IMessage message, Player player)

// v1.0 控制台实现
ConsoleMessageBridge extends AbsMessageBridge:
    send(msg)        → System.out.println(msg.getContent())
    send(msg, player) → System.out.println("[" + player.getPlayerName() + "] " + msg.getContent())
```

### Game 暴露

```java
AbsMessageBridge getMessageBridge()    // 所有 Command 通过此方法获取桥接
```

### 使用规范

所有 Command 中禁止 `System.out.println()`，统一改为：

```java
// 发给单人
game.getMessageBridge().send(new SinglePlayerMessage("You took the Sword."), player);

// 全局广播
game.getMessageBridge().send(new GlobalMessage("Welcome to World of Zuul!"));
```

## Issue #11 — AttackCommand 对战系统（gmy → 供 Game 调用，依赖 #9）

**包路径：** `cn.edu.whut.sept.zuul.game.combat`

### AttackCommand

```java
// cn.edu.whut.sept.zuul.game.command.AttackCommand extends Command
class AttackCommand extends Command:

    execute(Game, Player):
      1. 无 secondWord → "Attack whom?"
      2. 通过 GameWebSocketHandler.getOnlinePlayers() 查找目标
      3. 目标不在同一房间 → "That player is not here!"
      4. 检查冷却（距上次攻击 < 2s → "You cannot attack yet!"）
      5. 计算伤害：damage = attacker.attack - target.defense（最小 1）
      6. target.hurtBy(damage)，触发 onHurt 事件
      7. 反击：counter = (int)(target.attack * 0.5) - attacker.defense（最小 0）
      8. attacker.hurtBy(counter)
      9. 任一方血量 ≤ 0：
         - 触发 onDeath 事件
         - 失败者物品掉落房间
         - 失败者属性重置（attack=10, defense=5, health=100）
         - 失败者传送回起点
         - 胜利者触发 onFightWin 事件
      10. 通过 GameMessageBridge 广播战斗结果
```

### 玩家事件系统

```java
// cn.edu.whut.sept.zuul.game.combat.event
interface IPlayerListener:
    void onHurt(Player player, AttackEvent event)
    void onDeath(Player player, DeathEvent event)
    void onFightWin(Player player, FightWinEvent event)

class AttackEvent:
    Player attacker
    Player target
    int damage

class DeathEvent:
    Player killer
    Player victim

class FightWinEvent:
    Player winner
    Player loser
```

      1. 从数据库读取 JSON
      2. 反序列化为 Store
      3. 先创建所有 Room 对象，按编号放入 List
      4. 根据 exits Map 重建房间连接
      5. 根据 itemNames 用 Items.createItem() 还原物品
      6. 创建 Player 对象，按编号还原位置和历史

    // Game 新增（供 Command 调用）
    // Game 中新增：
    //   StoreManager getStoreManager()
    //   void setStoreManager(StoreManager)

## 开发依赖顺序

```
          ┌──────────────────┐
          │ #10 HTTP API/用户  │ (lfk 先做！提供 JWT)
          └────────┬─────────┘
                   │ Token 就绪
          ┌────────▼─────────┐
          │ #9 WebSocket 通信 │ (lfk，需 Token 鉴权)
          └────────┬─────────┘
                   │ 在线玩家就绪
          ┌────────▼──────────────────┐
          │ #11 AttackCommand 对战     │ (gmy，需获取在线玩家)
          │   + 4个事件装备             │
          │   + Player 新增 listeners  │
          └────────┬──────────────────┘
                   │
          ┌────────▼─────────┐
          │ #12 数据库持久化   │ (lfk，依赖 #2 #3 #4)
          └──────────────────┘
```

**关键阻塞关系：**
- lfk 的 **#10 必须最先完成**，否则 #9 的 WebSocket 没 Token 鉴权
- gmy 的 **#11 依赖 #9** 的 GameWebSocketHandler 获取在线玩家列表
- **#12 可与 #11 并行**，它只需 #2 #3 #4（v1.0 已完成）

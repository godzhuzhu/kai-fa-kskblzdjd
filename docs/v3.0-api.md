## Issue #15 — 前端路由配置 + 整体框架（zy）

### 项目初始化

```bash
npm create vite@latest frontend -- --template vue
cd frontend
npm install vue-router element-plus gsap
```

### vite.config.js

```js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5173,
    proxy: {
      '/api': 'http://localhost:8080',
      '/game': {
        target: 'http://localhost:8080',
        ws: true
      }
    }
  }
})
```

### 路由配置

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | HomeView.vue | 登录/注册页 |
| `/game` | GameView.vue | 游戏主界面（需登录） |

路由守卫：`/game` 无 token 时重定向到 `/`。

```js
// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', component: () => import('../views/HomeView.vue') },
  { path: '/game', component: () => import('../views/GameView.vue'), meta: { requiresAuth: true } }
]

const router = createRouter({ history: createWebHistory(), routes })

router.beforeEach((to, from, next) => {
  const token = sessionStorage.getItem('token')
  if (to.meta.requiresAuth && !token) {
    next('/')
  } else {
    next()
  }
})

export default router
```

### 页面组件结构

```
App.vue                      # 根组件 + GSAP 切换动画 + <router-view>
├── HomeView.vue             # 组合 HomeBackground + Home

│   └── Home.vue             # 登录/注册表单
└── GameView.vue             # 渲染 Game.vue
    └── Game.vue             # 游戏主界面
```

### 页面切换动画

```js

// 路由切换时对 <router-view> 做 fadeIn/fadeOut
```

### 样式规范

- Element Plus 主题定制
- 响应式布局

### 验收标准

- 访问 `/` 显示登录/注册页

## Issue #13 — 前端：登录/注册页面 HomeView（zy）

### 页面元素

- 背景视频/动画效果
- 游戏标题展示
- 登录表单（用户名 + 密码 + 登录按钮）
- 注册表单（用户名 + 密码 + 确认密码 + 注册按钮）
- 登录/注册切换 Tab
- 表单校验（用户名不为空、密码长度≥6、两次密码一致）
- 错误提示（用户名已存在、密码错误等）

### HTTP 接口对接

#### 注册

```
POST /api/user/register
Content-Type: application/json

Request:
{
  "username": "player1",
  "password": "123456"
}

Response 成功:
{
  "success": true,
  "message": "OK",
  "data": "Registration successful"
}

Response 失败:
{
  "success": false,
  "message": "Username already exists",
  "data": null
}
```

#### 登录

```
POST /api/user/login
Content-Type: application/json

Request:
{
  "username": "player1",
  "password": "123456"
}

Response 成功:
{
  "success": true,
  "message": "OK",
  "data": {
    "userId": 1,
    "token": "eyJhbGciOiJIUzI1NiJ9..."
  }
}

Response 失败:
{
  "success": false,
  "message": "Invalid username or password",
  "data": null
}
```

### 登录成功后的操作

- 将 `token` 存入 `sessionStorage.setItem('token', data.token)`
- 跳转到 `/game`

### 验收标准

- 注册成功可登录
- 登录成功跳转游戏页
- 错误情况有提示
- 已登录用户刷新 `/` 自动跳 `/game`

## Issue #14 — 前端：游戏主界面 GameView + WebSocket（zy）

### WebSocket 连接

#### 连接地址

```
ws://localhost:8080/game/websocket?token={jwt_token}
```

开发环境通过 Vite proxy 代理，代码写法：
```js
const token = sessionStorage.getItem('token')
const ws = new WebSocket(`ws://${location.host}/game/websocket?token=${token}`)
```

#### 心跳

每 30 秒发送一次：
```json
{ "action": "heartbeat", "data": null }
```

后端 60 秒未收到心跳自动断连。

#### 断线重连

```js
ws.onclose = () => {
  setTimeout(() => { /* 重新 new WebSocket(...) */ }, 3000)
}
```

### 客户端 → 服务端 消息格式

```json
{
  "action": "command",
  "data": "go east"
}
```

| action | data 格式 | 说明 |
|--------|----------|------|
| `"command"` | 命令字符串 | 发送游戏命令 |
| `"heartbeat"` | null | 心跳包 |

### 服务端 → 客户端 消息格式

```json
{
  "type": "playerPush",
  "data": { ... }
}
```

| type | data 类型 | 说明 |
|------|----------|------|
| `"playerPush"` | PlayerVO | 玩家自身状态更新（登陆后首次推送、每次命令执行后刷新） |
| `"roomPush"` | RoomVO | 当前房间状态更新（房间信息、物品、出口、同房间玩家） |
| `"messagePush"` | 字符串 | 系统消息（命令执行结果、战斗消息等） |

### PlayerVO（自身状态 - playerPush 的 data）

```json
{
  "userId": 1,
  "playerName": "Player1",
  "attack": 10,
  "defense": 5,
  "currentHealth": 100,
  "maxHealth": 100,
  "maxCapacity": 50,
  "currentLoad": 0,
  "bagItemNames": ["Sword", "MagicCookie"],
  "currentRoomName": "outside"
}
```

### RoomVO（房间状态 - roomPush 的 data）

```json
{
  "name": "outside",
  "description": "outside the main entrance of the university",
  "items": ["Sword", "BloodVial"],
  "exits": ["east", "south", "west"],
  "players": [
    {
      "userId": 2,
      "playerName": "Player2",
      "currentHealth": 80,
      "maxHealth": 100
    }
  ],
  "portal": false
}
```

### RoomPlayerVO（players 数组中的元素）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | int | 玩家 ID |
| playerName | String | 玩家昵称 |
| currentHealth | int | 当前血量 |
| maxHealth | int | 最大血量 |

### 可发送的命令列表

| 命令 | 格式 | 说明 |
|------|------|------|
| go | `go <east/west/south/north>` | 移动到相邻房间 |
| back | `back` | 回到上一个房间 |
| take | `take <物品名>` | 拾取物品 |
| drop | `drop <物品名>` | 丢弃物品 |
| use | `use <物品名>` | 使用道具 |
| attack | `attack <玩家名>` | PvP 攻击 |
| save | `save` | 保存游戏 |
| load | `load` | 读取存档 |
| help | `help` | 帮助 |
| quit | `quit` | 退出游戏 |

### 界面布局

```
┌──────────────┬──────────────────────────────┬──────────────┐
│   左栏 25%   │         中栏 50%              │  右栏 25%    │
│              │                              │              │
```

### 快捷操作

- 方向按钮：点击发送 `go east` 等
- back 按钮：发送 `back`
- 物品操作：点击物品名弹出 take/drop/use 操作菜单
- 攻击：点击同房间玩家名发送 `attack <name>`
- help / save / load 快捷键

### 数据流

```
登录成功 → sessionStorage存token → 跳转/game
进入/game → new WebSocket(token) → 收到 playerPush + roomPush → 渲染界面
用户点击按钮 → ws.send({action:"command", data:"go east"})
后端处理 → 推送更新后的 playerPush + roomPush → 重新渲染
```

### 验收标准

- 登录后能看到自身状态（左栏）
- 能看到同房间玩家（右栏）
- 点击方向按钮可移动，界面实时刷新
- 物品拾取/丢弃/使用正常
- 消息区域显示系统消息
- 断线后自动重连

## WebSocket 事件流

```
客户端                          服务端
  │                               │
  │── connect?token=jwt ─────────→│ 鉴权通过，player.setOnline(true)
  │←── playerPush (PlayerVO) ────│ 首次推送自身状态
  │←── roomPush (RoomVO) ────────│ 首次推送房间状态
  │                               │
  │── heartbeat ─────────────────→│ 每 30s
  │                               │
  │── {action:"command", data} ──→│ 执行命令
  │←── playerPush (PlayerVO) ────│ 刷新自身状态
  │←── roomPush (RoomVO) ────────│ 刷新房间状态
  │←── messagePush (String) ─────│ 命令执行结果
  │                               │
  │── 关闭 / 超时 ───────────────→│ player.setOnline(false)
```

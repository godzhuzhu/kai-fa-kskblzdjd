
## 2. 路由配置

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | HomeView.vue | 登录/注册页 |
| `/game` | GameView.vue | 游戏主界面（需登录） |

路由守卫：`/game` 无 token 时重定向到 `/`。

```js
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', component: () => import('../views/HomeView.vue') },
  { path: '/game', component: () => import('../views/GameView.vue'), meta: { requiresAuth: true } }
]

const router = createRouter({ history: createWebHistory(), routes })

router.beforeEach((to, from, next) => {
  const token = sessionStorage.getItem('token')
  if (to.meta.requiresAuth && !token) {
    next('/')
  } else {
    next()
  }
})

export default router
```

## 3. HTTP API

### 注册

```
POST /api/user/register
Content-Type: application/json

Request:
{
  "username": "player1",
  "password": "123456"
}

Response 成功:
{
  "success": true,
  "message": "OK",
  "data": "Registration successful"
}

Response 失败:
{
  "success": false,
  "message": "Username already exists",
  "data": null
}
```

### 登录

```
POST /api/user/login
Content-Type: application/json

Request:
{
  "username": "player1",
  "password": "123456"
}

Response 成功:
{
  "success": true,
  "message": "OK",
  "data": {
    "userId": 1,
    "token": "eyJhbGciOiJIUzI1NiJ9..."
  }
}

Response 失败:
{
  "success": false,
  "message": "Invalid username or password",
  "data": null
}
```

登录成功后将 `token` 存入 `sessionStorage.setItem('token', data.token)`。

## 4. WebSocket 连接

### 连接地址

```
ws://localhost:8080/game/websocket?token={jwt_token}
```

开发环境通过 Vite proxy 代理，前端代码写：
```js
const token = sessionStorage.getItem('token')
const ws = new WebSocket(`ws://${location.host}/game/websocket?token=${token}`)
```

### 心跳

每 30 秒发送一次：
```json
{ "action": "heartbeat", "data": null }
```

后端 60 秒未收心跳断连。

### 断线重连

```js
ws.onclose = () => {
  setTimeout(() => { /* 重新 new WebSocket(...) */ }, 3000)
}
```

## 5. WebSocket 消息格式

### 5.1 客户端 → 服务端

```json
{
  "action": "command",
  "data": "go east"
}
```

| action | data 格式 | 说明 |
|--------|----------|------|
| `"command"` | 命令字符串 | 发送游戏命令 |
| `"heartbeat"` | null | 心跳包 |

### 5.2 服务端 → 客户端

```json
{
  "type": "playerPush",
  "data": { ... }
}
```

| type | data 类型 | 说明 |
|------|----------|------|
| `"playerPush"` | PlayerVO | 玩家自身状态更新 |
| `"roomPush"` | RoomVO | 当前房间状态更新 |
| `"messagePush"` | 字符串 | 系统消息 |

## 6. 数据结构 (VO)

### PlayerVO（自身状态）

```json
{
  "userId": 1,
  "playerName": "Player1",
  "attack": 10,
  "defense": 5,
  "currentHealth": 100,
  "maxHealth": 100,
  "maxCapacity": 50,
  "currentLoad": 0,
  "bagItemNames": ["Sword"],
  "currentRoomName": "outside"
}
```

### RoomVO（房间状态）

```json
{
  "name": "outside",
  "description": "outside the main entrance of the university",
  "items": ["Sword", "BloodVial"],
  "exits": ["east", "south", "west"],
  "players": [
    {
      "userId": 2,
      "playerName": "Player2",
      "currentHealth": 80,
      "maxHealth": 100
    }
  ],
  "portal": false
}
```

### RoomPlayerVO（同房间其他玩家）

```json
{
  "userId": 2,
  "playerName": "Player2",
  "currentHealth": 80,
  "maxHealth": 100
}
```

## 7. 可发送的命令列表

| 命令 | 格式 | 说明 |
|------|------|------|
| go | `go <east/west/south/north>` | 移动 |
| back | `back` | 回退 |
| take | `take <物品名>` | 拾取 |
| drop | `drop <物品名>` | 丢弃 |
| use | `use <物品名>` | 使用道具 |
| attack | `attack <玩家名>` | PvP 攻击 |
| save | `save` | 存档 |
| load | `load` | 读档 |
| help | `help` | 帮助 |
| quit | `quit` | 退出 |
